LINGO AZ — Android Studio layihəsi (test prototipi)

Bu ZIP Android Studio-da açılmaq üçün hazırlanmış layihədir. Hazır APK deyil.

APK düzəltmək:
1. Kompüterə Android Studio quraşdırın.
2. ZIP-i çıxardın.
3. Android Studio -> Open -> çıxardığınız LingoAZ qovluğunu seçin.
4. Gradle sync tamamlanana qədər gözləyin.
5. Build -> Build Bundle(s) / APK(s) -> Build APK(s) seçin.
6. APK adətən app/build/outputs/apk/debug/app-debug.apk ünvanında yaranır.
7. APK-ni telefona göndərib quraşdıra bilərsiniz (telefon kənar mənbələrdən quraşdırmaya icazə istəyə bilər).

Play Market üçün:
- Google Play Console hesabı tələb olunur.
- İstehsal üçün imzalanmış Android App Bundle (.aab), məxfilik/siyasət məlumatları,
  tətbiq ikonu, ekran görüntüləri və Google Play-in cari test tələbləri lazımdır.
- Bu prototip ilkin test üçündür; söz bazası və oyun qaydaları yayımdan əvvəl yoxlanmalıdır.

Layihə offline işləyir; internet icazəsi tələb etmir.
